My agent burned 10,000 tokens researching my deadline, then asked me what it was — it was in the message it had just quoted back to me.

## Run it

```sh
node main.ts
```

The program prints the roast from `one-line.txt` (135/200 characters) after validating it: one line, no carriage returns, no leading or trailing space, and ending with terminal punctuation.
